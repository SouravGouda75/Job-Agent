# Machine Learning Engineer / Data Scientist (Remote)
**Company**: Global AI Solutions  
**Location**: Remote  
**Employment Type**: Full-Time  

### About the Role:
We are seeking a talented Machine Learning Engineer / Data Scientist to build and deploy generative AI, predictive models, and scalable MLOps pipelines. You will collaborate with software engineering teams to integrate LLMs, deep learning models, and real-time APIs into our core enterprise platform.

### Responsibilities:
- Design, train, fine-tune, and evaluate deep learning and machine learning models for production applications.
- Develop data pipelines and feature stores using Python, Pandas, and PyTorch / TensorFlow.
- Deploy ML models as high-performance REST APIs using FastAPI or Flask in containerized Docker environments.
- Implement MLOps workflows including model tracking with MLflow, version control, and automated CI/CD.
- Optimize model inference latency using quantization and model serving engines (e.g., vLLM, TensorRT).
- Collaborate with product managers and engineers to understand business metrics and translate requirements into algorithmic solutions.

### Required Qualifications:
- 2+ years of hands-on experience in Machine Learning, Data Science, or AI Engineering.
- Strong proficiency in Python and scientific computing libraries (NumPy, Pandas, Scikit-learn).
- Experience with Deep Learning frameworks: PyTorch or TensorFlow.
- Experience with Large Language Models (LLMs), prompt engineering, and fine-tuning (HuggingFace transformers).
- Proficiency with Docker, Linux command line, and Git version control.
- Experience building RESTful APIs using FastAPI.
- Familiarity with MLOps tools (MLflow, Kubeflow, or DVC) and cloud deployment (AWS or GCP).
