# Generative AI & Machine Learning Engineer (Remote)
**Company**: NextGen AI Systems  
**Location**: Remote  
**Employment Type**: Full-Time  

### About the Role:
We are seeking an experienced Generative AI & Machine Learning Engineer to architect and build production-grade LLM applications, multimodal speech systems, and high-throughput RAG microservices. You will lead development of intelligent agentic pipelines, optimize on-device inference, and build scalable backend APIs.

### Key Responsibilities:
- Design, optimize, and deploy production Retrieval-Augmented Generation (RAG) pipelines leveraging dense vector embeddings, BM25 lexical search, and cross-encoder re-ranking.
- Deploy and optimize local and cloud Large Language Models (LLMs) using Ollama, vLLM, and HuggingFace with quantized weights and prompt engineering.
- Architect high-performance asynchronous REST microservices using Python, FastAPI, and Docker.
- Build real-time streaming audio and speech processing systems utilizing Whisper, WebSockets, and PyTorch.
- Implement distributed observability, telemetry, and structured tracing across microservices using OpenTelemetry.
- Conduct latency profiling, bottleneck analysis, and caching to reduce end-to-end inference delays.

### Required Skills & Qualifications:
- Proficiency in Python, PyTorch, Scikit-learn, NumPy, and Pandas.
- Proven experience with Generative AI, RAG architectures, LangChain, and Vector Databases.
- Hands-on experience developing REST APIs and microservices with FastAPI and WebSockets.
- Experience with containerization (Docker), Git version control, and Linux environments.
- Familiarity with telemetry tools (OpenTelemetry, Grafana) and modern database systems (MongoDB, PostgreSQL).
